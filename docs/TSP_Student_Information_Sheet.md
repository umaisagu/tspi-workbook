## J. TSPi Role Preferences

Rank each role from 1 (least preferred) to 5 (most preferred); several roles may share a rank. Every member also develops and owns at least one feature (FR-IDs) through issue → branch → PR → CI. Roles are assessed under 'Role assignment' (Peer/Individual Evaluation) and 'Team work' (Project Evaluation). In a 6-member team, one role is shared by two members.

| TSPi role (project role) | Main responsibilities and evidence produced |
| --- | --- |
| Team Leader (Scrum Master & Client Contact) | Runs sprint and weekly meetings; WEEK reports and meeting minutes; main contact for client meetings; leads Team Evaluation; owns client acknowledgement form and final submission package |
| Development Manager (Tech Lead & AI Integration) | Flutter architecture and state management; SDS (UML, ERD, component and interface design); AI API integration and fallback; coding style; reviews and merges PRs to main |
| Planning Manager (Product Owner & Schedule Lead) | Requirement elicitation and SRS (FR-IDs); product backlog and requirement changes; TASK, SCHEDULE, SUMTASK and earned value; GitHub Projects board and milestones M1–M4 |
| Quality/Process Manager (QA & Test Lead) | Test plan; LOGTEST, LOGD, SUMQ, SUMP; unit, widget and integration tests (≥50 cases); CI gate and ≥60% coverage; UAT with the client |
| Support Manager (DevOps & Documentation Lead) | Repository, branch protection and GitHub Actions; secrets and API key protection; LOGAI and CCR; release APK v1.0.0; README and user manual |
